# 课程表 · Course Schedule

面向大学生的移动端课表工具。**React 18 + TypeScript + Vite**，零后端、零登录，  
数据全部存在本机浏览器，打开即用。

> 软件工程个人作业 · 2026 秋季学期  
> 需求文档见仓库根目录的 [`docs/requirements.md`](../docs/requirements.md)，网页原型见 [`prototype/index.html`](prototype/index.html)

---

## 一、快速开始

### 1. 安装依赖

```bash
cd course-schedule-app
npm install
```



> 国内网络慢的话加镜像：`npm install --registry=https://registry.npmmirror.com`

### 2. 电脑上先跑起来

```bash
npm run dev
```

终端会输出：

```
  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.x.x:5173/
```

浏览器打开 `http://localhost:5173/` 即可看到课表。  
**建议按 `F12` 打开开发者工具，切到手机模拟视图（iPhone 尺寸）**，因为这是移动端优先的界面。

### 3. 手机上调试运行（重点）

项目已经配置了 `server.host = true`，也就是 `npm run dev` 默认就对外开放局域网访问，  
不需要额外加 `--host` 参数。

**步骤：**

1. **确认电脑和手机连的是同一个 Wi-Fi**（这一步最容易出错，尤其是电脑插网线、手机连 Wi-Fi 的情况）。
2. 启动开发服务器：`npm run dev`。
3. 在终端输出的 `Network:` 一行里找到地址，形如 `http://192.168.1.23:5173/`。
4. 手机浏览器地址栏输入这个地址 → 打开就是课表。
5. 想让微信里也能打开？把链接发到「文件传输助手」，在微信里点开即可验证微信内置浏览器的表现。

**改代码后手机会自动刷新**（Vite HMR 会通过 WebSocket 推送），不用来回重启。

#### 连不上怎么办？按这个顺序排查

| 现象              | 原因               | 处理                                                                                                  |
| --------------- | ---------------- | --------------------------------------------------------------------------------------------------- |
| 手机打不开，一直转圈      | Windows 防火墙拦了    | 首次运行 Vite 时系统会弹「是否允许访问」，必须勾选**专用网络**并允许。若当时点了取消，去「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」里手动放行 Node.js |
| 电脑能访问、手机不能      | 两端不在同一网段         | 对比电脑的 `ipconfig` 和手机的 Wi-Fi 详情页，看前三段是否一致（都是 `192.168.1.x` 才算同网段）                                    |
| 校园网 / 公司网下怎么都不通 | 路由器开了 AP 隔离      | 用手机开热点，让电脑连手机热点，再用手机浏览器访问 `http://电脑IP:5173`                                                        |
| 昨天能连，今天不行       | 电脑重新联网后局域网 IP 变了 | 重新看终端里的 `Network:` 地址即可                                                                             |

#### 想在手机上真正调试（看 console、断点）

- **An~~droid~~**~~：手机开启「开发者选项 → USB 调试」并用数据线连电脑，  
  电脑 Chrome 打开 `chrome://inspect`，就能直接调试手机上的页面。~~
- **~~iOS~~**~~：需要 Mac + Safari 的「开发」~~菜单。Windows 下可以在代码里临时引入 `vconsole`  
  在手机屏幕上显示日志，排查完再删掉。

## 三、功能清单

### 核心功能

- **周课表**：7 天 × 12 节的网格，跨节次的课程纵向连成一条色带；今天所在的列会高亮
- **课程登记**：课程名、教师、地点、星期、起止节次、起止周次、单双周、颜色、备注
- **编辑 / 删除**：点课程格即可编辑；删除前有二次确认
- **周次导航**：根据开学日期自动算出「现在是第 X 周」，可前后翻周，一键回到本周
- **数据持久化**：任何改动立即写入 localStorage，关掉浏览器再打开数据还在

### 锦上添花

- **今日视图**：时间轴列出今天的课，含上课时间段
- **智能导入**（v2.1）：把教务系统复制的课表文字、或截图「提取文字」的结果粘贴进来，  
  自动解析出星期 / 节次 / 周次 / 地点 / 教师，先给你一张可编辑的预览表核对，确认后才导入
- **节次作息可配置**（v2.1）：每节上下课时间可改、节次数可增删（4~16）、可恢复默认，  
  各校作息不同也能用；改动实时反映到课表格子与今日页
- **冲突检测**：同一时段已有课时给出提示（不硬拦，由你决定）
- **单双周**：格子右上角显示「单 / 双」角标，只有该上的周次才显示
- **课程库**：列表浏览全部课程，直接增删改
- **深色模式**：跟随设置切换，偏好会记住
- **导入导出**：导出 JSON 备份，换设备时导入恢复
- **异常兜底**：本地数据被改坏时自动回退到默认值，不会白屏

## 六、几个设计取舍

- **不用状态管理库**：全局状态只有「课表数据 + 用户偏好 + 界面瞬时状态」三块，  
  一个自定义 Hook 就够了，引 Redux 属于给自行车装飞机引擎。
- **不用 UI 组件库**：课表网格是强定制界面，组件库能复用的部分还不如它带来的体积和样式覆盖成本。
- **不用日期库**：整份代码只用到「两个日期差几天」和「格式化」，用原生 `Date` 足够，省下 20KB。
- **课表数据不展开存**：只存「每周这天这几节、这些周次上」，具体某一节课在渲染时现算，  
  这样改一门课的时间不会留下脏数据。
- **样式用单文件 + CSS 变量**：主题切换只需换一组变量值，不用为每个组件写一份深色样式。

## 七、数据存放位置

课表存在浏览器的 `localStorage`，键名 `course-schedule:v2`（内部数据结构版本 v3，  
旧的 v2 数据会自动迁移补上作息表）。这意味着：

- 换浏览器、换设备、清理浏览器数据 → 课表会丢，**建议定期在「我的」页导出备份**
- 数据不会上传到任何服务器，不涉及隐私问题
- 用无痕模式打开时可能无法保存，界面上会给出提示
